## 📝 正文

救命！用 Claude Code 做项目一个月，token 烧到心痛才摸索出这套省钱流程🔥 真心建议所有在 CC 里踩过坑的姐妹码住！

### ❌ 新手常犯的错：直接和 CC 对话

一开始我也是打开 CC 就开始聊天式开发，结果复杂项目跑下来，token 消耗直接翻倍💀

其实 CC 更像是"神经系统"——负责连接大脑（LLM）和手脚（你的代码工具）。直接跟它对话，等于让神经系统先帮你翻译需求，白白浪费大量 token！

### ✅ 正确打开方式：四步走流程

**1️⃣ 网页端免费 LLM 先沟通 🧠**
deepseek、qwen、豆包、kimi…国内网页版大模型基本都是免费的！先在这里把需求聊透，让模型完全理解你要做什么。

**2️⃣ 让 LLM 写 CC 专用提示词 📝**
需求确认无误后，直接让它生成一份给 Claude Code 执行的 AI 提示词。

**3️⃣ 多模型交叉验证 🔍**
把提示词丢给另一个 LLM 过一遍：
- ✅ 方案是否可行？
- ⚠️ 有没有潜在风险？
- 🎯 能否覆盖需求里的关键点？

循环验证，等大部分模型都说 OK 再给 CC 执行！

**4️⃣ CC 执行 + 网页端验证结果 ✅**
把优化好的提示词喂给 CC，跑完后再用网页 LLM 检验结果合理性。

### ⚠️ 三个血泪注意事项

🔒 **隐私数据一定要脱敏！** 网页模型会把你的数据传到厂商服务器用于模型改进。涉及隐私的数据/图片，改成上传结构类似的数据表或匿名化截图！

🚫 **提示词里必须加限制！** 明确写上"不能修改或删除其它文件夹数据"，防止 CC 误操作全局文件，真的会谢！

🔌 **Skills 插件提前装！** 建议先装好 find-skills 插件，后面 CC 推理到需要什么 Skills 时会自动检索并提示你下载，省心省力！
